# Settled — affiliate site

Static site for [settled.world](https://settled.world). Astro 4.x,
deploys to Vercel on every push to `main`. Articles are Markdown files
in `src/content/articles/` generated by the togha-agent pipeline.

## How articles get here

The agent runs in `togha-agent` (separate repo). Article generation:

1. The affiliate writer (`app/agents/affiliate_writer.py`) picks a
   topic from its catalog (small-space-kitchen niche).
2. Picks are harvested from Amazon's PA-API or from a curated fallback
   list.
3. The critic gate (`app/agents/affiliate_critic.py`) runs structural
   checks (FTC disclosure, brand voice, partner tag in every link,
   word count band, no placeholder copy).
4. If the critic passes, the writer drops a Markdown file into
   `src/content/articles/{slug}.md`.
5. Operator (or future cron) runs `git add . && git commit && git push`.
6. Vercel auto-deploys on push.

## Local dev

```bash
cd affiliate_site
npm install
npm run dev          # localhost:4321
npm run build        # static build → dist/
npm run preview      # serve the built site
```

## Content schema

Articles must match `src/content/config.ts`. The togha-agent writer
emits matching front matter — keep these in sync if you change either
side.

## Front matter shape

```yaml
---
title: "The magnetic knife strips worth your wall space"
slug: "magnetic-knife-strips-small-kitchens"
description: "Three picks tested on counter-starved kitchens."
date: "2026-05-04T12:00:00Z"
category: "small-space-kitchen"
tags: ["knife storage", "small kitchen", "wall-mounted"]
pickCount: 4
asins: ["B000000001", "B000000002", "B000000003", "B000000004"]
wordCount: 850
draft: false
---
```

## Deploy

Connected to Vercel. Push to `main` triggers an auto-deploy. Custom
domain is `settled.world` (configured in Vercel project settings).
DNS records live in the registrar.
